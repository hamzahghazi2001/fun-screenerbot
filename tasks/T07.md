## New `.github/workflows/build.yml`
- Header comment (2-4 lines): fork build, Linux x64 headless only, upstream's multi-platform release workflow removed.
  The words electron, macos, windows, aarch64 must not appear anywhere in the file (the check below is case-insensitive).
- `name: Build`
- `on:` `push: tags: ['v*']` and `workflow_dispatch:` (no inputs).
- Keep upstream's `concurrency` block (`group: build-${{ github.ref }}`, `cancel-in-progress: true`), `permissions: contents: read`,
  and the whole `env:` block with its comments unchanged (`CARGO_TERM_COLOR`, `RUST_BACKTRACE`, `CARGO_INCREMENTAL: 0`,
  `CARGO_NET_RETRY: 10`, `RUSTUP_MAX_RETRIES: 10`).
- One job, id `build-linux-headless`, `name: Rust · Linux x64 headless`, `runs-on: ubuntu-22.04`, `timeout-minutes: 90`. Steps:
  1. checkout: the same pinned `actions/checkout@11d5960a326750d5838078e36cf38b85af677262 # v4` with `persist-credentials: false`.
  2. toolchain: the same pinned `dtolnay/rust-toolchain@4cda84d5c5c54efe2404f9d843567869ab1699d4 # stable`,
     `toolchain: 1.98.1`, `targets: x86_64-unknown-linux-gnu`.
  3. cache: the same pinned `Swatinem/rust-cache@6323deb102c322ba6fcbdcafc7e3dddab59af2b6 # v2.9.2`,
     `key: x86_64-unknown-linux-gnu`, `cache-on-failure: true`.
  4. `id: version`, bash: on a tag push `VERSION="${GITHUB_REF_NAME}"`, otherwise
     `VERSION="v$(grep -m1 '^version' Cargo.toml | sed -E 's/.*"([^"]+)".*/\1/')-${GITHUB_SHA::7}"`;
     on a tag push also fail if `${VERSION#v}` differs from the Cargo.toml version (same check and message as upstream's
     `Tag $VERSION does not match Cargo.toml $CARGO_VERSION`). Write `version=$VERSION` to `$GITHUB_OUTPUT`.
     Use `github.event_name == 'push'` / `$GITHUB_REF_TYPE = tag` to detect the tag. No Electron version check.
  5. build: `cargo build --release --locked --target x86_64-unknown-linux-gnu --bin screenerbot` (default features,
     same as upstream's Linux leg).
  6. glibc report: `objdump -T target/x86_64-unknown-linux-gnu/release/screenerbot | grep -o 'GLIBC_[0-9.]*' | sort -uV | tail -1`
     printed with an `echo "Highest required glibc: ..."` line. Informational only, it must not fail the job.
  7. package: same as upstream's "Package headless binary (Linux)" step, producing
     `ScreenerBot-${{ steps.version.outputs.version }}-Linux-x64-headless.tar.gz` containing `screenerbot` (chmod +x).
  8. upload: the same pinned `actions/upload-artifact@ea165f8d65b6e75b540449e92b4886f43607fa02 # v4`,
     `name: headless-Linux-x64`, `path:` the tarball, `if-no-files-found: error`, `retention-days: 14`.
- Quote every `${{ ... }}` used inside `run:` scripts through `env:` where it is a user-controllable value; the
  version comes from `GITHUB_REF_NAME`/`GITHUB_SHA` env vars inside the script, not `${{ }}` interpolation.
