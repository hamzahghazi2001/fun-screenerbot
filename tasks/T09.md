## API
```rust
pub fn dynamic_trade_size(balance_sol: Option<f64>, cfg: &TraderConfig) -> anyhow::Result<f64>
pub fn slot_cap(balance_sol: Option<f64>, sol_usd: Option<f64>, cfg: &TraderConfig) -> usize
```
`balance_sol` is `Option` so "balance unknown" is a type, not a sentinel 0.

### dynamic_trade_size
1. `None` balance → Err. Non-finite or `<= 0` balance → Err.
2. `dynamic_size_pct` must be finite and in `(0, 100]` → else Err.
3. `dynamic_size_floor_sol` and `dynamic_size_ceiling_sol` must be finite, floor `> 0`,
   floor `<= ceiling` → else Err (no silent swap).
4. `size = (balance * pct / 100).clamp(floor, ceiling)`.
5. `size > balance` → Err (the floor can exceed a tiny balance; never size a buy above the balance).
   Fees/rent reserve are left to the upstream pre-trade checks.
6. Does not check `dynamic_size_enabled`; the caller (T10) decides.

### slot_cap
- `base = cfg.max_open_positions`.
- Return `base` when: balance or price is `None`, non-finite or `<= 0`; the USD product is non-finite;
  `third_slot_threshold_usd` is non-finite.
- `balance * price >= threshold` (exact compare, no epsilon) → `max(base, third_slot_max_positions)`
  (crossing the threshold never lowers the cap); else `base`.
- Does not check `dynamic_size_enabled`; the caller decides.
