## Rules under test (already implemented, see `evaluate_series`)
5m bucket = 300 s. Closed = `ts + 300 <= evaluated_at`. Need `L + W + 1` closed candles (defaults 24 + 12 + 1 = 37),
else `Err(InsufficientCandles { indicator: "breakout retest", available, required })`. Newest stored candle older than
3 buckets (`age > 900 s`) → `Err(StaleCandleData)`. Latest breakout `i` = newest index in the last `W + 1` candles whose
close is strictly above the max high of the `L` candles before it. Band = level × (1 ± tol). Every retest close `>= band_low`;
some retest low within `[band_low, band_high]`; a candle in `s[i..=last]` whose body or range move is strictly above
`max_candle_change_pct` → false; with `require_higher_low`, min retest low strictly above min low of `s[i-L..=i]`.

## Tests (`#[tokio::test] async fn`, use the file's `eval` / `eval_err` helpers)
1. `breakout_retest_tolerance_exactly_1_5_pct`: fresh rows, every retest row `(101, 102, 98.5, 101)` (low exactly on
   band_low) → `true`. Retest row 28 = `(101, 102, 98.5, 98.5)` (close exactly band_low), others unchanged → `true`. Every retest row
   `(101.6, 102, 101.49, 101.8)` → `true`; every retest row `(101.6, 102, 101.51, 101.8)` → `false` (low outside the band). Do **not** test a low of exactly `101.5`:
   `100.0 * (1.0 + 0.015)` rounds to `101.49999999999999` in f64, so that value is not the band edge. Add that as a comment.
2. `breakout_retest_candle_change_exactly_25_pct`: fresh rows with row 24 = `(100, 125, 100, 125)` (body and range exactly
   25%) → `true`. Row 24 = `(100, 125.01, 100, 125.01)` → `false`. Also with `retest_cond(12, 1.5, 24.0, true)` and the
   first series → `false`.
3. `breakout_retest_23_candles_is_err`: drop row 0 (breakout preceded by only 23 candles, 36 closed) → `eval_err` matches
   `StrategyError::InsufficientCandles { indicator: "breakout retest", available: 36, required: 37 }`. Then the same 36 rows plus
   one forming candle at `anchor_ts()` (`(101,102,100.5,101)`, newest_ts = anchor_ts()) → same error with `available: 36`
   (the forming candle is not counted).
4. `breakout_retest_24_candles_ok`: the full 37 rows fresh → `true` (24 candles before the breakout).
5. `breakout_retest_forming_candle_excluded`: 37 rows fresh plus a forming row `(101, 102, 49, 50)` at `anchor_ts()` → `true`.
6. `breakout_retest_stale_series_is_err`: 37 rows with `newest_ts = anchor_ts() - 4 * BR_STEP` (age 1200 s > 900) →
   `StrategyError::StaleCandleData { .. }`. With `newest_ts = anchor_ts() - 3 * BR_STEP` (age exactly 900) → `true`.
7. `breakout_retest_no_retest_touch_false`: every retest row `(101.8, 102, 101.6, 101.9)` → `false`.
8. `breakout_retest_close_below_level_false`: retest row 28 = `(101, 102, 98.4, 98.4)` (close below band_low) → `false`. Retest row 28 =
   `(101, 102, 99.0, 99.0)` (close below the level 100 but inside the band) → `true`.
9. `breakout_retest_higher_low_required`: retest row 30 `(101, 102, 97.9, 101)` → `false` with `default_retest()`,
   `true` with `retest_cond(12, 1.5, 25.0, false)`. Row 30 low exactly `98.0` (equal to base low) → `false` with the flag on.
10. `breakout_retest_retest_window_expired_false`: 38 rows fresh (base rows plus one more retest row, so the breakout is 13
    candles before the newest) → `false` with `default_retest()`. The base 37 rows with `retest_cond(5, 1.5, 25.0, true)` → `false`
    (breakout 12 candles back, window 5). The base 37 rows with `retest_cond(12, ..)` → `true`.
