## Algorithm (closed candles only; the forming candle is excluded explicitly)
```
candles      = get_candles_for_timeframe(ctx, timeframe)?          // Err: no bundle / no tf / empty / stale
bucket       = Timeframe::from_str(tf).to_seconds()                // tf = param or ctx.strategy_timeframe
now          = ctx.evaluated_at.timestamp()
closed       = closed_candles(candles, bucket, now)                // sort by timestamp asc, keep ts + bucket <= now
L, W         = resistance_lookback, retest_window
need         = L + W + 1
if closed.len() < need -> Err(InsufficientCandles { indicator: "breakout retest", available, required: need })
s            = last `need` candles of closed                       // index 0..need-1, last = need-1
if any candle in s has open/high/low/close non-finite or <= 0 -> Err(MissingContextData { data: "OHLCV data" })
evaluate_series(s, &params) -> Result<bool>                        // pure fn, below
```
`evaluate_series(s, p)` (pure, `s.len() == L + W + 1`):
```
// latest breakout: scan i from last down to L (W+1 candidates)
for i in (L..=last).rev():
    level = max(s[i-L..i].high)              // the L candles strictly before i
    if s[i].close > level: breakout = (i, level); break
none found               -> false
i == last                -> false            // broke out on the newest closed candle, no retest yet
R = s[i+1..=last]                            // 1..=W retest candles
tol = p.tol_pct / 100
band_low = level * (1 - tol); band_high = level * (1 + tol)
vertical: any c in s[i..=last] with |c.close - c.open| / c.open * 100 > max_pct
                               or (c.high - c.low) / c.low * 100 > max_pct      -> false
hold:  every c in R has c.close >= band_low                                       else false
touch: some c in R has band_low <= c.low && c.low <= band_high                    else false
higher low (only if p.require_higher_low):
       min(R.low) > min(s[i-L..=i].low)                                           else false
true
```
Boundaries: exactly `max_candle_change_pct` passes (strict `>`); a low or close exactly on `band_low` passes;
equal lows fail the higher-low test (strict `>`). Candle counts are stored candles, not wall-clock buckets
(no-trade buckets are never stored), the same as every other candle condition; say so in the `//!` doc.
`closed_candles` and `evaluate_series` are private free functions. No `unwrap()`/`expect()` outside `#[cfg(test)]`.
The file needs the BUSL header + a `//!` doc (copy the 2-line header from `price_breakout.rs`) and `// FORK: F2`
under the header.

## Err vs false
| Input | Result |
|---|---|
| missing bundle, unknown/missing timeframe, empty series, stale series (> 3 buckets) | Err (from `get_candles_for_timeframe`) |
| any param missing, wrong type, out of range, non-whole, NaN | Err |
| fewer than `L + W + 1` closed candles | Err `InsufficientCandles` |
| a used candle with NaN/inf/≤0 open, high, low or close | Err `MissingContextData { data: "OHLCV data" }` |
| no breakout among the last `W + 1` candles; breakout only on the newest closed candle; hold, touch or higher-low fails; a vertical candle | `Ok(false)` |
